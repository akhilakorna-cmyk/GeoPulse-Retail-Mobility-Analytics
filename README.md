
# GeoPulse: Hyper-Local Retail Mobility Analytics

## Project Overview
GeoPulse is a Data Analytics project designed to analyze
retail footfall, customer mobility patterns, store performance,
and geographical trends.

## Objectives
- Collect retail mobility datasets.
- Clean and preprocess data.
- Analyze customer footfall patterns.
- Identify peak visiting hours.
- Analyze geographical trends.
- Create interactive dashboards.
- Generate actionable business insights.

## Technologies Used
- Python 3.13
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Jupyter Notebook
- Power BI
- GitHub

## Project Structure
- dataset/ - Dataset files
- notebooks/ - Analysis notebooks
- src/ - Python source code
- dashboard/ - Dashboard files
- reports/ - Project reports
- images/ - Visualization images
